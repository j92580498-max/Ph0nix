# Ph0nix 1.0

Native emulator builds for Windows, Linux and Android, with an original
pixel-art button-phone logo. Import the supported Sony Ericsson K750i MAIN and FS
files through the app's Library. First boot can take several minutes.

## Changes

- Fixed the Android app's Settings crash. Its Material 3 switch used the wrong
  theme attributes and attempted to measure a null On/Off label when the tab
  became visible. Settings now uses the Material Components switch with label
  text beside the control. Preferences persist normally.
- Added the button-phone logo to the Android launcher and library, desktop window and
  header, browser header and favicon. Editable pixel artwork and a reproducible
  exporter are included under `assets/branding/` and `scripts/`.
- Included native audio decoder, mailbox, MIDI sequencing, PCM and AMR work,
  checkpoint preservation, bounded diagnostics, and UART receive timing for
  firmware-managed OBEX transfers.
- Published the complete DB2010 board patch and subsequent authenticated
  patches against the public QEMU release commit. Source builds verify patch
  bytes and output identities and preserve unrelated local edits.
- Included the required Samsung backend crate with its original source bytes
  and Apache-2.0/MIT notices, so builds need no private repository access.

## Media verification and remaining work

This release is an emulator under development. It does not establish full
hardware or audio equivalence with a K750i; no reference handset is available.

| Feature | Firmware verification | Remaining work |
| --- | --- | --- |
| MP3 | `cbr44.mp3`: stereo 44.1 kHz playback, pause/resume, progress and natural completion, with no reported underruns in the captured run | Seek, next/previous and the complete CBR/VBR, sample-rate and ID3 matrix remain unverified |
| MIDI | The firmware service loudspeaker test generated MIDI PCM; sequencing and controller tests cover timing, note release, pitch bend, volume and checkpoints | The current triangle synth does not reproduce SEMC instrument samples or banks; original timbre equivalence remains incomplete |
| 3GP | `h263s.3gp` was uploaded through firmware OBEX and read back with an identical SHA-256 | Synchronized H.263/MPEG-4 SP video with AMR playback, pause and seek are not complete |
| Other sounds | Decoder, PCM, AMR and audio pause/checkpoint checks; firmware service loudspeaker path exercised | Complete ringtone, alarm, notification, key-click, mixer/routing and microphone verification remains incomplete |

MP4 support has not been added, and MP4 files were not used in this work.
Camera capture, cellular service and original analog hardware behavior remain
incomplete. Existing compatibility shims and their scope are documented in
[native applications](../native-apps.md) and [K750i bring-up](../k750i.md).

## Builds

Windows and Linux archives contain the native launcher, the DB2010 engine,
build provenance, component licenses and usage documentation. Windows archives
include the required MinGW DLLs. Linux packages are built on Ubuntu 24.04 and
require glibc 2.38 or later, plus GTK 3, GLib, ALSA, XKB and libfdt runtime
libraries. Android targets ARM64 and Android 7.0/API
24 or later. The APK is a non-debuggable release variant signed with the
project's existing development certificate for upgrade compatibility.

Native Rust tests, Android Settings rendering/preferences regressions, APK
signature/API/JNI/ELF checks and the packaged engine's DB2010 machine query are
part of build verification. Interactive Windows and physical Android device
tests are not claimed. Firmware MAIN/FS images and personal phone state are
not distributed in the release.

Clone the source with `git clone --recurse-submodules
https://github.com/j92580498-max/Ph0nix.git`. See
[native build instructions](../native-apps.md) for each platform.
